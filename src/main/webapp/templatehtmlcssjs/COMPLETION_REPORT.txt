🎯 HOW TO USE
================================================================================

1. MỞ WEBSITE
   Windows: start index.html
   Mac: open index.html
   Linux: xdg-open index.html

2. HOẶC DÙNG SERVER
   python -m http.server 8000
   http://localhost:8000

3. TÍNH NĂNG ĐỂ THỬ
   - Scroll carousels (click ❮ ❯)
   - Search sách
   - Filter theo category/price/author
   - Thêm vào giỏ hàng
   - Xem chi tiết sách
   - Làm checkout
   - Đọc about + contact page
   - Mở FAQ (click để expand)

4. TEST RESPONSIVE
   - F12 (DevTools)
   - Ctrl+Shift+M (Toggle mobile)
   - Resize window to test: 1024px, 768px, 600px, 375px
